GC → XO 뇌신왕 이식 패치툴

Super Robot Taisen GC의 **거대 카라쿠리 뇌신왕** 관련 리소스를 Super Robot Taisen XO에 이식하는 Windows용 단일 실행 파일입니다. 일본어 원본 XO와 검증된 한글패치 1.0 XO를 하나의 EXE에서 선택할 수 있습니다.

## 다운로드

- [XO_GC_Import_V103.exe](./XO_GC_Import_V103.exe)

현재 릴리스의 SHA-256:

```text
0965f7bcca35f90c30046157aa857944f3f79b3def8b9a43a6829ba4a20b12aa
```

## 포함 범위

이 도구는 GC에서 확인된 뇌신왕 관련 데이터를 XO 형식으로 변환합니다.

- 뇌신왕 모델·텍스처·무기·전투 모션
- 검·방패·크래시 연출 및 전투 카메라 데이터
- GC 이벤트, 획득 플래그, 갈아타기/파일럿 연동
- 로봇 도감 설명과 관련 이름
- 전투 대사 25개 및 전용 음성 19개
- 일본어 원본용 데이터와 한글패치 1.0용 데이터

전체 게임을 새로 만들거나 GC의 모든 기체를 자동 변환하는 범용 변환기는 아닙니다. GC 원본과 적용할 XO 데이터가 모두 필요합니다.

## 요구 사항

- Windows 10/11 64-bit
- GC 일본어 원본 파일 또는 추출 폴더
- 적용 대상 XO 파일 또는 추출 폴더
- 변환 중 임시 공간 약 3GB 이상

Python, 별도 Dolphin 설치, 별도 DolphinTool 설치는 필요하지 않습니다. DolphinTool과 필요한 런타임 DLL은 EXE 안에 포함되어 실행 시 임시 폴더에 풀립니다.

## 사용 방법

### 1. 백업

Xenia를 종료하고 XO 원본 폴더를 통째로 백업하세요. 패치툴은 입력 파일과 세이브를 직접 수정하지 않지만, 사용자가 출력 파일을 복사하는 단계에서 원본을 덮어쓸 수 있습니다.

### 2. EXE 실행

`XO_GC_Import_V103.exe`를 실행합니다. 보안 경고가 표시되면 파일의 SHA-256을 확인한 뒤 실행하세요.

### 3. 언어 선택

- **일본어 원본**: 일본어 XO에 적용
- **한글패치 1.0**: 검증된 XO 한글패치 1.0에 적용

선택한 언어와 다른 XO 파일을 넣으면 해시 검증에서 중단됩니다.

### 4. 입력·출력 경로 지정

다음 세 경로를 지정합니다.

1. **GC 일본어 원본**: ISO/GCM/RVZ/GCZ/WIA 파일 또는 Dolphin으로 추출한 폴더
2. **XO 입력**: XO ISO 또는 XO 추출 폴더
3. **새 출력 폴더**: 아직 존재하지 않는 빈 경로

XO가 ISO인 경우에도 최종 적용에는 XO 추출 폴더가 필요합니다. 패치툴의 결과는 ISO가 아니라 교체용 게임 파일 10개이기 때문입니다.

### 5. 변환 실행

`변환 시작`을 누르고 로그가 성공으로 끝날 때까지 기다립니다. 변환 중에는 Xenia나 입력 파일을 열거나 이동하지 마세요. 완료되면 출력 폴더에 다음 파일이 생성됩니다.

```text
default.xex
config.pak
add00dat.bin
add01dat.bin
add02dat.bin
bpilot.pak
srwxse.pak
SRWXCharaVoice.xwb
r707.pak
r707_g.pak
```

### 6. XO에 적용

Xenia를 종료한 상태에서 위 10개 파일을 **같은 언어의 XO 추출 폴더**에 복사합니다. 기존 파일은 백업해 두고, 복사 후 Xenia에서 해당 XO를 실행합니다.

패치툴은 입력 폴더, 입력 ISO, 세이브 파일을 자동으로 덮어쓰지 않습니다. 출력 폴더를 확인한 뒤 사용자가 직접 복사해야 합니다.

## 정상 진행과 테스트 치트

배포 빌드는 일반적인 게임 진행을 기준으로 합니다. 다음 기능은 의도적으로 포함하지 않았습니다.

- 1화 → 서브9 → 33화 조기 진행 선택
- 적 HP 1 고정
- 아군 파일럿 능력치 MAX
- 실드 방어 100% 강제 발동

따라서 실제 획득 조건과 시나리오 플래그는 XO의 일반 진행 규칙을 따릅니다.

## 오류가 발생할 때

- **언어/해시 불일치**: 언어 선택을 확인하고 깨끗한 일본어 XO 또는 검증된 한글패치 1.0 XO를 사용하세요.
- **GC 파일 인식 실패**: 일본어 원본인지 확인하고, 압축 파일을 임의로 수정하지 마세요. RVZ/GCZ는 내부 파일이 온전해야 합니다.
- **출력 폴더 오류**: 기존 폴더 안에 다시 출력하지 말고 새로운 경로를 지정하세요.
- **Xenia에서 변화가 없음**: Xenia를 완전히 종료한 뒤 10개 파일을 같은 XO 폴더에 복사했는지, 올바른 언어 폴더를 실행했는지 확인하세요.
- **변환 중 중단**: 입력 파일이 다른 프로그램에서 열려 있지 않은지 확인하고 새 출력 경로로 다시 실행하세요. 완성되지 않은 출력 폴더는 사용하지 마세요.

실행 파일과 같은 위치에 오류가 기록되는 경우 `last_error.txt`를 함께 확인할 수 있습니다.

## 검증 정보

V103은 일본어와 한글패치 1.0 입력을 각각 실제로 변환하여 다음을 확인했습니다.

- 두 언어 모두 교체 파일 10개 생성
- GC 이벤트 28개 및 전투 대사 25개 검증
- 내장 리소스 51개 해시 검증
- 내장 DolphinTool을 임시 폴더에서 직접 실행
- 출력 해시가 검증된 V102 제작 결과와 일치
- 정상 종료 후 임시 추출 폴더 정리

이는 파일 변환·구조 검증 결과이며, 모든 전투 장면의 실기 렌더링이나 전체 회차 플레이를 의미하지는 않습니다.

## 내장 DolphinTool 및 라이선스

EXE에는 DolphinTool과 실행에 필요한 DLL, 변환 소스 스냅샷, 라이선스 문서가 포함되어 있습니다. 공식 Dolphin 소스 리비전은 다음과 같습니다.

```text
409881c34357d0f105fd473167d15ab0bd9c1628 (Dolphin 2609a)
```

프로그램의 `사용법 · 라이선스` 화면에서 내장 소스와 라이선스를 별도로 내보낼 수 있습니다. Dolphin 및 포함 라이브러리의 저작권·라이선스는 해당 문서를 따릅니다.

## 주의 및 권리

이 프로젝트는 원본 게임을 소유한 사용자가 개인적인 백업과 호환성 연구를 위해 사용하는 것을 전제로 합니다. 게임 ISO, XO 원본 데이터, 세이브, GC 음원 자체를 배포하지 않습니다. 원본 게임과 패치 사용에 관한 권리 및 책임은 사용자에게 있습니다.

## 출처 및 감사

모델·이벤트·전투 데이터의 기준은 Super Robot Taisen GC 일본어 원본이며, XO 적용 레이아웃과 한글패치 폰트 호환성에 맞추어 변환했습니다. 사용자 제공 번역 CSV는 원문을 임의로 재번역하지 않고 그대로 반영했습니다.
